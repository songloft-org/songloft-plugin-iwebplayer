# iWebPlayer



## 📱 项目简介

iWebPlayer 是 SongLoft 的主题插件之一，专为 iPhone 交互优化，媲美原生APP的音乐播放与小爱音箱控制。

- ✅ iPhone Safari 播放适配

- ✅ 提供PWA/配置直装，类似原生APP界面
    
- ✅ iPhone锁屏控制、灵动岛、媒体库完美体验

- ✅ 耳机线控支持（上一曲 / 下一曲 / 暂停）
    
- ✅ iPhone锁屏动态歌词显示    
  
- ✅ 歌曲封面 & 歌词自动刮削展示

- ✅ 支持自建歌单（添加/删除歌曲，自定义封面）

- ✅ 支持倍速播放，记忆续播

- ✅ 调用Songloft的LXMusic，WebDAV插件

- ✅ 推送小爱音箱播放Songloft本地或其他在线资源歌曲
