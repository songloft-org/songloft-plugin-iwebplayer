# iWebPlayer

A Songloft JS plugin generated by `create-songloft-plugin`.

## Development

```bash
npm install
npm run dev         # watch + auto-upload to local Songloft
npm run build       # produce dist/iwebplayer.jsplugin.zip
npm run validate    # verify plugin.json hashes
```

## Description

适配iPhone的Web播放器
